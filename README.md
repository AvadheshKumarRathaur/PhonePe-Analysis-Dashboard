# 📊 PhonePe Transaction Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **PhonePe Analysis Dashboard** developed using Microsoft Power BI.

The dashboard focuses on analyzing digital payment transactions and transforming transaction data into meaningful business insights through interactive visualizations, KPIs, and data-driven analysis.

The objective of this project is to explore transaction trends, understand payment behavior, and demonstrate practical data analytics skills.

## 🎯 Project Objectives

- Analyze digital payment transaction data.
- Identify transaction trends and patterns.
- Understand payment behavior and transaction performance.
- Create interactive visualizations for better decision-making.
- Present complex data in a clear and understandable format.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| Microsoft Power BI | Dashboard development and visualization |
| Power Query | Data cleaning and transformation |
| DAX | Calculated measures and KPIs |
| Excel / CSV | Data preparation and analysis |

## 📈 Dashboard Features

- Interactive dashboard with visual analytics.
- KPI cards for important transaction metrics.
- Data-driven charts and graphs.
- Transaction trend analysis.
- Interactive filters and slicers.
- Visual representation of payment data.

## 🔍 Key Insights

The dashboard helps explore the following aspects of digital payments:

- Transaction volume and transaction value.
- Payment trends across different periods.
- Service Transactions Value Analysis
- Transaction performance and patterns.
- Top 5 Users (By Transaction value)
- Transaction Value MOM% & Total Transaction MOM%
- Distribution of digital payment activity.
- Business insights derived from transaction data.


## 🚀 How to Use

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `Phonepe_Analysis_Dashboard.pbix`.
4. Refresh the data if the source file is available.
5. Explore the dashboard using interactive filters and visualizations.
